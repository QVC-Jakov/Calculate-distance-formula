# Project Title FA1_Distance-Calculator

## Description
Takes the primary and secondary values of X and Y, and subtracts the two (X2-X1) and (Y2-Y1),after which squares the difference before getting the sum of the X value and Y value after the subtracting, and getting the square root of the total sum.

## How to Run
1. Enter the X1 and the Y1 values.
2. Enter the X2 and the Y2 values.
3. The program runs and gives you the total distance.

## Input Needed
- X1 and Y1
- x2 and Y2

## Sample Output
Enter x1:2

Enter y1:3

Enter x2:4

Enter y2:5

the total distance is  2.8284271247461903
